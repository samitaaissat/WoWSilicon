# WoWSilicon 3.0.0 is here. No CrossOver required.

WoWSilicon now ships its own Wine. Download one app, select your game folder, apply the game patch, and play.

## Bundled Wine runtime

- WoWSilicon.app now contains a pre-patched Wine runtime built from the public `WineAndAqua/wine` tree (`wine-11.14-macos`) — no CrossOver purchase, install, or patching step.
- The CrossOver path selection and the CrossOver patch step are gone from the dashboard.
- Already-patched game folders stay valid; the obsolete `rosettax87` folder inside the game directory is cleaned up automatically.

## Portable by design

- Everything WoWSilicon needs now lives in a `WoWSilicon Data` folder right next to the app: your settings and a **dedicated, private Wine environment**. Copy the app and that folder together and your whole setup moves — another folder, an external drive, a new Mac.
- WoWSilicon no longer uses the shared `~/.wine` prefix, so it can never fight with CrossOver, other launchers, or system Wine again — the number-one cause of "my settings randomly reset."
- The first launch sets up the new Wine environment explicitly, with progress shown (it can take a few minutes on the first run — the app tells you instead of looking frozen).
- One-time notes for upgraders: Option-as-Alt is re-applied automatically from your settings; re-enable High Resolution mode and reinstall the VC++ runtime once from Options (the dashboard will show them as disabled/not installed). Your old `~/.wine` is left untouched — a new "Delete Legacy Wine Prefixes" button in Troubleshooting can clean it up if nothing else on your Mac uses Wine.
- If the app runs from a read-only place (like the DMG), it temporarily keeps data in `~/Library/Application Support/WoWSilicon` and adopts the portable folder automatically once you move it somewhere writable. Troubleshooting shows which location is active.
- Force Quit is now scoped to WoWSilicon's own Wine — it no longer kills other Wine apps on your Mac, and it asks the Wine server to save your registry before stopping.

## rosettax87_JIT

- Updated to the latest build, with macOS 27 support.
- Now lives inside the app bundle instead of the game folder, so runtime updates can no longer break the Play button.
- On first launch, macOS asks once to authorize debugging. The loader needs this to run the 32-bit client; approve it once and you will not be asked again.

## CrossOver

- Going forward, WoWSilicon never touches a CrossOver install.
- If a 2.x version patched your CrossOver, the new "Restore CrossOver modifications" button in Troubleshooting reverts those changes.

## Download size

- The DMG is now around 170 MB because the Wine runtime ships inside the app.

As always, drag it into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```

Supported versions: macOS 15, macOS 26, macOS 27
