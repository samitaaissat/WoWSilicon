# WoWSilicon 3.0.1 — d9mt performance pass 3

A patch release that bundles d9mt renderer payload v7, the third performance pass for the experimental d9mt renderer (Options → General → Renderer).

## d9mt payload v7

- **Fixed-function transform constants split hot/cold.** The per-draw constant-buffer upload that dominated CPU time in transform-heavy scenes is gone: the three per-draw matrices now travel in the push-constant block instead of re-uploading a renamed buffer on every draw. In the targeted microbenchmark this cut app-thread submit time by about half (~8,000 buffer uploads per frame reduced to zero). Model-heavy views are where you should feel it.
- **Two smaller CPU cuts in the particle-heavy path** — a buffer-lock fast path and a draw-preparation fast path. Honest numbers: about 1% in the particle microbenchmark; kept because they are simple and verified correct.
- **Correctness hardening.** Auto-generated mipmaps now regenerate in the same draw that uploads a texture (caught in review before it could ship), and the renderer gained compile-time layout tripwires and loud overflow checks around the new push-constant layout.

Existing installs do not need this app update to get the renderer improvements: the runtime self-update ships payload v7 automatically within a day. This release bundles it so new downloads start current.

Nothing else changed in the app itself.
