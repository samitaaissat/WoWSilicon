# WoWSilicon 3.2.1 — d9mt fix, foreign-thread crash fix

## Fixed: d9mt ground-decal clipping regression

An experimental d9mt renderer change shipped between releases (payload v5)
narrowed a Metal texture-usage flag to restore lossless compression on
colour textures, per Apple's WWDC21 GPU-optimization guidance. It caused a
regression: a previously-fixed bug where projected ground decals (target
rings on NPCs, and similar projected textures) clip/z-fight into terrain
came back. This release (payload v6) reverts that specific change; the
extensive investigation that went into diagnosing it, and why it was
reverted rather than chased further, is in
[docs/gpu-optimization-wwdc21-10148.md](../gpu-optimization-wwdc21-10148.md).

If you use the d9mt renderer and have background updates enabled,
WoWSilicon likely already fetched payload v6 on its own — the fix isn't
gated on installing this app version. This release also gets fresh installs
onto the fixed payload immediately.

## Fixed: wine crash from a foreign-thread fault handler bug

Wine was silently swallowing faults that occurred on non-Wine (Metal/
libdispatch) threads instead of reporting them, which could look like the
game "closing for no reason" with no crash log. The bundled Wine runtime
is bumped to fix this.

## Other

- Fixed a Swift 6 concurrency error that blocked the test suite from
  compiling (internal, no user-facing behavior change).

As always, drag the app into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```
