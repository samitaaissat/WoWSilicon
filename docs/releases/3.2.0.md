# WoWSilicon 3.2.0 — pick your renderer

This is the first public release of the 3.x line. If you are updating from 2.5.x, you get everything from 3.0.0 as well: WoWSilicon now **ships its own Wine** (no CrossOver required) and is **fully portable** — the app plus its `WoWSilicon Data` folder next to it hold your entire setup. See the [3.0.0 notes](3.0.0.md) for the details and one-time upgrade steps.

## New: Renderer picker — three Direct3D 9 backends

A per-version **Renderer** picker in Options lets you choose how the game's Direct3D 9 is translated to your Mac's GPU:

- **d9vk (default, unchanged)** — DXVK's D3D9 over Vulkan/MoltenVK. The proven path; nothing changes if you never touch the picker.
- **d9mt (experimental)** — a Direct3D 9 → Metal translation layer that skips the Vulkan/MoltenVK hop entirely. Requires the Xcode command line tools (`xcode-select --install`); the picker checks before letting you switch.
- **wined3d (experimental, new in 3.2.0)** — Wine's own built-in Direct3D 9, running on its Vulkan renderer through MoltenVK. Unlike the other two it puts **no translation DLL in your game folder** and lives entirely inside the bundled Wine runtime. Wine's Vulkan renderer only recently learned everything WoW-era D3D9 needs — you are among the first to run these clients on it, so expect different performance and visuals than d9vk and switch back if anything misbehaves.

Switching renderers re-stages the game patch automatically; switching back to d9vk restores the exact previous behavior. The troubleshooting debug log now records the active renderer, and switching is blocked while a patch operation is running instead of silently doing nothing.

### Known limitation: MSAA is not supported under d9mt

With Multisampling (MSAA) enabled, d9mt cannot present the multisampled frame and the game shows a **fully black screen** — the game still runs (music, login, Metal HUD all work), but nothing is drawn. Before using d9mt, set Multisampling to **Off** in WoWSilicon's Graphics settings **and** in the in-game Video options (the in-game setting can re-enable it behind the app's back). d9vk and wined3d are unaffected.

## Also in this release

- macOS **Game Mode** support: the game process is recognized by macOS and gets Game Mode's performance and latency priorities.
- **MSync** toggle (experimental) for faster Wine synchronization.
- Rollback safety: settings written by newer versions can no longer reset your game list on older 3.2.0+ builds.

As always, drag the app into your Applications directory and run:

```sh
xattr -cr /Applications/WoWSilicon.app
```

Supported versions: macOS 15, macOS 26, macOS 27
